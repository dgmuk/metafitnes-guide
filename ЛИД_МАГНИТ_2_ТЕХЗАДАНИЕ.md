### БЛОК 6: СИСТЕМА — ГОДОВОЙ МАКРОЦИКЛ

**Заголовок:**
```
Как устроен год тренировок
```

**Вводный текст:**
```
Профессиональный тренинг не выглядит как "пришёл в зал
и сделал что написано в программе". Он устроен как
архитектурный проект: сначала фундамент, потом стены,
потом отделка. Каждый этап готовит почву для следующего.
Это называется периодизация.
```

**Визуальная шкала года (горизонтальная, с анимацией заполнения):**

```
ГОД
[Блок 1       ][Блок 2          ][Блок 3    ][Блок 4       ]
 Адаптация     Основной рост      Сила        Реализация
 Нед 1–10      Нед 11–28          Нед 29–40   Нед 41–52
```

Каждый блок кликабельный, при клике/тапе раскрывается описание.

**Блок 1: Адаптация (нед 1–10)**
```
Самый важный и самый недооценённый этап. Тело учится
работать с нагрузкой: суставы, сухожилия, нервная система.
Объём начинается с минимального эффективного (MEV)
и плавно нарастает. Те кто пропускает этот этап
и сразу "бомбит" с максимальной нагрузки, потом
удивляются болям и застою через 2 месяца.
```

**Блок 2: Основной рост (нед 11–28)**
```
Главный рабочий период. Объём нагрузки находится
в зоне MAV (максимального адаптивного объёма) для
каждой мышечной группы. Диапазоны повторений меняются
от тренировки к тренировке (волнообразная периодизация).
Каждые 4–5 недель идёт делоад — неделя снижения нагрузки
для суперкомпенсации.
```

**Блок 3: Сила (нед 29–40)**
```
Накопленная масса конвертируется в силу. Работа
с весами 80–95% от максимума, меньший объём,
больший отдых. Нейромышечная система адаптируется
к работе с субмаксимальными весами. После этого блока
возвращение к гипертрофийному тренингу даст
значительно больший отклик.
```

**Блок 4: Реализация (нед 41–52)**
```
Закрепление результатов, переходный период, оценка
прогресса за год. Объём снижается до поддерживающего.
Отличное время для работы над техникой и отстающими
группами. Конец года это начало нового цикла,
и он всегда начинается на более высоком уровне.
```

## HTML РАЗМЕТКА — КЛЮЧЕВЫЕ КОМПОНЕНТЫ

### Анимация появления при скролле

```html
<div class="fade-in">...</div>

<!-- JS: -->
<script>
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.fade-in').forEach(el => {
  observer.observe(el);
});
</script>

<!-- CSS: -->
<style>
.fade-in {
  opacity: 0;
  transform: translateY(24px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}
.fade-in.visible {
  opacity: 1;
  transform: translateY(0);
}
</style>
```

### Sticky навбар

```html
<nav class="navbar" id="navbar">
  ...
</nav>

<script>
window.addEventListener('scroll', () => {
  const navbar = document.getElementById('navbar');
  if (window.scrollY > 50) {
    navbar.classList.add('scrolled');
  } else {
    navbar.classList.remove('scrolled');
  }
});
</script>

<style>
.navbar {
  position: sticky;
  top: 0;
  z-index: 100;
  transition: background 0.3s, backdrop-filter 0.3s;
}
.navbar.scrolled {
  background: rgba(13,13,13,0.92);
  backdrop-filter: blur(12px);
  border-bottom: 1px solid var(--border);
}
</style>
```

### Раскрывающиеся карточки целей

```html
<div class="goal-card" onclick="toggleGoal(this)">
  <div class="goal-header">
    <span class="goal-icon">💪</span>
    <span class="goal-title">НАБОР МЫШЕЧНОЙ МАССЫ</span>
    <span class="goal-arrow">↓</span>
  </div>
  <div class="goal-body">
    <p>Текст описания...</p>
  </div>
</div>

<script>
function toggleGoal(card) {
  const isActive = card.classList.contains('active');
  document.querySelectorAll('.goal-card').forEach(c =>
    c.classList.remove('active')
  );
  if (!isActive) card.classList.add('active');
}
</script>
```
